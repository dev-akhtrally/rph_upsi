AKTiVA-RPH — Educational Blog
==============================

Cara guna:
1. Buka index.html dalam browser.
2. Semua CSS dan JavaScript berada secara lokal.
3. Tiada framework atau URL luaran diperlukan.
4. Gantikan placeholder [PERLU DIISI], [MASUKKAN ...] dengan sumber akademik sebenar.
5. Untuk deploy, muat naik keseluruhan folder ke hosting statik seperti GitHub Pages, Netlify atau platform setara.

Ciri:
- Responsive desktop/tablet/mobile
- Navigation sticky + mobile menu
- Unit 1–3
- Accordion strategi/aktiviti
- Self-check dengan feedback
- RPH Builder dengan live preview
- Checklist disimpan dalam localStorage
- Draft RPH boleh dimuat turun sebagai TXT
- Ruang sumber dan rujukan
- Fokus Pakaian dan Jahitan
